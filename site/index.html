How it works

One enrolment. Every participating platform. Zero shared data.

SafeGen doesn’t watch your child, scan their face, or sit on their phone. It simply lets platforms recognise a number a parent has vouched for — nothing more.

1

You vouch, once

You confirm you’re an adult, and that the mobile number your child uses belongs to someone under 16. A code sent to their phone proves the number is really theirs.

Best done together — many families pair it with the “you can have the phone, not the apps” conversation.

2

The number becomes a code

Before anything is stored, the number is transformed using keys split between two independent organisations. Neither can reverse it alone. The real number is destroyed in seconds.

This isn’t a pinky-promise deletion — the system has nowhere to store a phone number, and independent auditors verify that.

3

Platforms recognise, privately

When someone signs up (or already has an account) with that number, the platform’s own systems get a single quiet signal: a parent has vouched this number belongs to a minor.

The platform then runs its normal age process. If it’s ever wrong — say, a recycled number — an adult simply passes that check once. A wrong flag costs one extra check, not a lockout.

🛡️

Why this actually works when age checks alone don’t

Today, a determined 14-year-old just deletes the app, makes a new account, and types a new birthday — or tries the face-scan again until it passes. SafeGen changes the game because the signal follows the number, not the account. New account, new app, new email — same phone, same answer. And a confident selfie doesn’t move it, because SafeGen isn’t guessing anyone’s age. A parent said so, out-of-band.

Safety by architecture

“Is this a government database of children?” No. Here’s why it can’t become one.

We didn’t write a privacy policy and hope. We built a system where the scary version can’t be built quietly — breaking the promise would require two independent organisations acting together, in public view.

🧩

The keys are split

Unscrambling even one code needs two separate organisations — SafeGen and an independent trustee — to act together. A hacker, a rogue employee, or a demand served on either one gets random bytes.

Double-blind checks

Platforms check numbers in scrambled form, and the match happens on their side. We never learn which child is on which app. They never get a list — only answers about numbers they already have.

⏳

It forgets on schedule

Every record carries its own expiry: the month your child turns 16. It deletes itself — no request needed. And your undo key removes it any time before that, within 24 hours.

📊

Watched in public

Every system update and every platform’s query volume is published to a public, tamper-evident log — so unusual behaviour is visible to researchers and regulators, not just to us.

🏛️

Regulated, not run, by government

eSafety and the OAIC oversee and audit. They receive statistics, never data. There is no feed to any agency — nothing exists that could be fed.

🧯

A real off switch

If SafeGen ever had to shut down, destroying the two keys instantly turns every stored code — including any old backup, anywhere — into permanently meaningless noise.

Questions parents ask

Fair questions. Straight answers.

Can platforms see my child’s phone number or identity? +

They never receive anything from us. Platforms already have the phone numbers of their own users — that’s how signup works today. SafeGen only lets a platform check, in scrambled form, whether a number it already holds was vouched for by a parent. It learns yes or no. It cannot browse, search, or download a list, and it learns nothing about numbers it doesn’t already have.

What if my child gets a new number or a new phone? +

A new number means a fresh one-minute enrolment — we’ll never know about the change otherwise, because we don’t track anyone. A new phone with the same number changes nothing.

What happens when my child turns 16? +

The record deletes itself that month, automatically. Platforms stop seeing the signal, and SafeGen holds nothing about your child — there is no “dormant file”. You don’t need to do anything.

Can I undo this? +

Yes, any time. At enrolment you get an undo key — a short code we show you once. Enter it on this site and the record is removed within 24 hours. Lost the key? Removal is still possible with a confirmation code to the phone plus a fresh verified-adult check — so a parent can always undo it, but a child can’t quietly unenrol themselves.

Is this a government database? Will eSafety or police get the list? +

No — and this is the part we’re proudest of. There is no list. What we store is a set of scrambled codes that identify no one, reversible only if two independent organisations’ secure hardware were compromised at the same time. A subpoena served on SafeGen yields random bytes. Regulators audit how we operate; they receive statistics, never records.

What if someone enrols a number that doesn’t belong to a child — by mistake or maliciously? +

Three protections. First, enrolment requires receiving a code on that actual phone — you can’t flag a number you don’t hold. Second, the enrolling adult passes an identity check, so it’s never anonymous. Third — and most important — a SafeGen signal never blocks anyone by itself. It simply sends that account through the platform’s standard age check, which an adult passes once. The worst case of a wrong enrolment is one extra verification prompt, and any verified adult holding the phone can remove the record at any time.

Does my child know? Should they? +

Yes — the enrolment includes a code sent to their phone, so it’s designed to be done together, not behind their back. Parents tell us it lands best as part of a straightforward conversation: “This is the family rule until you’re 16, and it’s the same rule the law sets for every kid in Australia.”

Why should I trust you? Every company says they care about privacy. +

Don’t trust us — check us. Our protocol is published and independently reviewed; certified auditors verify that the system physically has no place to keep phone numbers; our query volumes and software versions sit in a public tamper-evident log; and Australia’s privacy regulator can (and does) hold us to section 63F, which makes keeping your data illegal, not just off-brand. The honest summary: we designed SafeGen so that trusting us is never the load-bearing part.

Is this compulsory? Whose idea is it? +

Entirely voluntary, and it exists because parents kept asking for something that actually works. Australia’s under-16 law made platforms responsible for keeping kids off — but their checks can be gamed and reset. SafeGen gives your decision, as the parent, a way to stick: across accounts, across apps, until 16.
